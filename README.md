# Client Hub shell package (generated)

Generated by deploy/gen-shell.mjs from repo/src/. Do not hand-edit;
regenerate: `npm run gen:shell` in deploy/ (set SHELL_ORIGIN to the
final shell origin when it exists).

Contents: index.html (with the deploy hub-config inlined) and
assets/app.js + assets/styles.css, byte-identical to repo/src.
Deploy this directory to the static host as-is; no build step there.

The shell's API base is absolute
(https://fafowzslfscgtahqokpu.supabase.co/functions/v1/client-hub),
so it works from any host origin. Cross-origin calls are answered
only when the client-hub function's CORS_ALLOWED_ORIGINS secret
names this shell's exact origin; until then the shell loads and
every API call is blocked by the browser, which is the expected
fail-closed state.

This shell intentionally has no service worker and no web app
manifest: the Client Hub source shell has neither, and nothing in
this package references files that do not exist.
